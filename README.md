# LakeRover — iPad app (demo)

Companion iPad app for the MCKK Robotics lake water-sampling rover.
"Dari Tasik ke Data. Dari Data ke Tindakan."

- Spec (Kiro): `.kiro/specs/lakerover-ipad-app/` — requirements → design → tasks
- Steering: `.kiro/steering/`
- Reality Composer contract: `docs/reality-composer-contract.md`
- Wireframes: `docs/wireframes/storyboard-v1.png (editable HTML available on request)`

## Build
Xcode 16+, iPadOS 18 SDK. `brew install xcodegen && xcodegen generate`, then open `LakeRover.xcodeproj`.
Demo mode (no rover) is available from the splash screen; long-press the logo for Showcase mode.
